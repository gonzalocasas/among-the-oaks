# Among the Oaks | Handoff package

**Live prototype:** https://gonzalocasas.github.io/among-the-oaks/ (published from `prototype/` to the `gh-pages` branch by `.github/workflows/pages.yml`).

**Start here:** `docs/HANDOFF.md` (full brief) or `docs/HANDOFF.pdf` (printable copy).

To try the current procedural rendering prototype:

```bash
./scripts/serve.sh
```

Then open http://localhost:8080 on the same computer. The current source **requires internet to load Three.js from jsDelivr**. This is NOT yet a verified production build or a photorealistic demo.

`concept-art/` contains AI-generated references only; none are screenshots from the prototype. See `docs/VALIDATION.md` for what was and was not tested.

The original code is in `prototype/`.
